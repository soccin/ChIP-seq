**#18 The `FDR` column of the differential analysis is Holm, not BH**
· `bug` `high` `pre-port` — `R/diffAnalysisPairwise.R` computes
`FDR = p.adjust(PValue)`, and the default method of `p.adjust` is
`"holm"`, a family-wise error correction that is stricter than the
Benjamini-Hochberg FDR (`method = "BH"`, what `topTags` reports). Peaks
are called significant at `FDR < 0.05`, so the lists are shorter than a
real FDR cutoff would give. Found 2026-11-16 while rewriting
`docs/output.md`, which now states what the column holds. Decide whether
Holm is intended; if not, change to `method = "BH"` (it changes every
result) and update `docs/output.md`, `docs/methods.md` and
`assets/tmpldeliveryEmail_04.txt`. The IHW result computed in the same
function is printed and not used.

**#20 MACS2 runs with its default `--keep-dup 1`** · `risk` `medium`
`pre-port` — `callPeaks_ChIPseq.sh` follows ENCODE's `macs2.py` but
leaves out `--keep-dup all`, so MACS2 keeps at most one read per
position and strand, on top of the duplicate removal in POST. Each read
of a pair is a separate BED interval, so pairs that are not duplicates
but share one 5' end lose a read. Found 2026-11-16 while writing
`docs/methods.md`, which states it as a difference from ENCODE. Decide
whether it is intended; adding the option changes the peak calls.

**#14 Mitochondrial reads are dropped before peak calling** · `risk`
`low` `pre-port` — POST keeps only the contigs of
`lib/genomes/<TAG>.genome` (autosomes, X, Y), so chrM/MT reads never
reach MACS2. v0.9.0 did the same (its `@SQ` regex kept only `1`-`9`,
`X`, `Y` and their `chr` forms). ENCODE's ChIP-seq pipeline keeps chrM
through peak calling (`filter_chrs=[]`) and removes chrM only from the
final filtered peaks; its ATAC-seq pipeline removes it before peak
calling (links in `../ATAC-seq/docs/GENOMES.md`). The difference changes
the read totals MACS2 uses to scale the control, so peak calls can
differ slightly from ENCODE's. The current behavior is now stated in
`docs/output.md` and, as a difference from ENCODE, in `docs/methods.md`
(2026-11-16). Still to decide: keep it or follow ENCODE. ATAC-seq now uses the same genome
files, so the decision applies to both repos. The `filter(Chr != "MT")`
in `R/diffAnalysisPairwise.R` has nothing to remove and does not cover
`chrM`; it can go once this is decided.
